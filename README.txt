GitHub Pages用ファイルです。

このzipを解凍して、中にある index.html / app.js / styles.css / .nojekyll を
GitHubリポジトリ kakomon-reflect の直下にアップロードしてください。

GitHub Pagesの設定は以下にしてください。

Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: / (root)

反映には数分かかることがあります。

共有コード機能:
サイトの「設定」画面にある「共有コード」で、記録と表示設定を書き出しできます。
別端末では同じ画面にコードを貼り付けて「読み込んで追加」または「全て置き換え」を選んでください。
